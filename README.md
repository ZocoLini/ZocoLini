Hi! I'm Borja, a backend and systems engineer with a background in mathematics.

I work at [Dash Core Group](https://github.com/dashpay) on the Rust SDK for the Dash blockchains, its FFI bindings, and the Swift/Kotlin wrappers built on top. Most of that lives in [rust-dashcore](https://github.com/dashpay/rust-dashcore) and [platform](https://github.com/dashpay/platform).
